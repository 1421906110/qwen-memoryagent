### 引擎核心
- 三元组提取（规则 + LLM 兜底）
- 事实网络去重与合并
- 三级矛盾检测（L1 deny / L2 conflict / L3 context）
- 置信度贝叶斯更新 + 来源权重 + 冷启动加速
- 三级路由召回（L0 缓存 → L1 精确 → L2 语义 → L3 向量）
- BM25 关键词模糊匹配
- 版本链追溯
- PostgreSQL 16 持久化（7 张表）

### Agent 能力
- 目标驱动执行（不达目标不停止）
- 自主规划（执行前先拆步骤）
- 自动纠错（pip install、mkdir、备份等）
- 记忆自管理（废话过滤 + 重要自动存）
- 12 个工具 + SelfReflector

### Web UI
- 聊天界面（流式输出）
- 仪表盘（8张卡片 + 2个图表 + 健康检测）
- 知识图谱可视化（Canvas + 节点过滤）

- 衰减曲线可视化

## 五、部署方式

```bash
# 服务器管理
sudo systemctl start|stop|restart|status cognimem.service

# 查看日志
tail -f /tmp/qwen-agent3.log

# 同步代码
rsync -avz --delete --exclude '.git' --exclude '.venv' --exclude '__pycache__' \
  --exclude '.env' --exclude '*.log' ./ \
  ecs-user@47.99.151.253:/home/ecs-user/qwen-memoryagent/

# 本地开发
cd ~/projects/qwen-memoryagent && source .venv/bin/activate
python -m uvicorn memory_agent.main:app --port 9999 --reload
```
