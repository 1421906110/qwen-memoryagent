## 二、已具备的能力

### 核心引擎
- 三元组提取（规则 30+ 模式 + LLM 兜底）
- 事实网络去重与合并
- 三级矛盾检测（L1 deny / L2 conflict / L3 context）
- 置信度贝叶斯更新 + 来源权重 + 冷启动加速
- 三级路由召回（L0 缓存 → L1 精确 → L1.5 BM25 → L2 语义 → L3 向量）
- 上下文感知排序（置信度×50% + 重要性×20% + 新鲜度×20% + 相关度×10%）
- BM25 关键词模糊匹配
- 记忆抽象化（碎片→高层归纳）
- 艾宾浩斯自适应遗忘（7~60天半衰期）
- 5 分钟空闲自动整合（异步不阻塞）
- 版本链追溯
- 推理链缓存（相似句 0 Token 复用）
- PostgreSQL 14 持久化

### Agent 能力（新）
- **🎯 目标驱动执行** — 不达目标不停止（最多 30 轮）
- **📋 自主规划** — 执行前先拆步骤，按计划推进
- **🔧 自动纠错** — pip install、mkdir、备份等自动修复
- **🛡 记忆治理** — 4 态过滤（PII 拦截 + 降级 + 矛盾标注）
- **🧠 记忆自管理** — 废话不存，重要自动存
- **🚀 10 个工具**：文件读写、Shell、Web 搜索/抓取、记忆召回/存储/状态
- **🌐 代理搜索** — 通过梯子访问 DuckDuckGo/Google
- **🔄 模型灵活切换** — Qwen ↔ DeepSeek 一键切换

- 阿里云 ECS：http://42.121.253.80:8000/
- Docker Compose：`docker compose up`
- PostgreSQL 14 持久化
