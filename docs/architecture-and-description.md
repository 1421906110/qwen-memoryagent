# CogniMem — 认知记忆系统

> 让 AI 不再"鱼的记忆"：不是死记硬背，而是**理解、归纳、遗忘、质疑**——像人脑一样。

---

## 项目简介

CogniMem 是一个面向 AI Agent 的认知记忆系统。不同于传统的向量数据库或简单的 KV 存储，CogniMem 将信息以**三元组结构**（主体-谓词-客体）存储，构建事实网络，并模拟人脑的**记忆机制**——包括矛盾检测、置信度动态更新、艾宾浩斯遗忘曲线、碎片信息抽象化等。

### 核心创新点

| 维度 | 做法 | 对比传统方案 |
|------|------|-------------|
| 🧠 **结构化记忆** | 三元组事实网络 + 图关系 | 普通 RAG 只存文本块 |
| 💰 **零 Token 提取** | 规则优先，LLM 兜底，相似句缓存复用 | Mem0 等每次调 LLM |
| ⚡ **科学遗忘** | 艾宾浩斯自适应衰减 + 访问频率修正 | 固定 TTL 或永不过期 |
| 🚀 **矛盾驱动学习** | 自动检测矛盾 → 主动追问 → 解决矛盾 → 知识进化 | 多数系统无此能力 |

```

│                    用户 / Agent                                  │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
┌─────────────────────────────────────────────────────────────────┐
│                    MemoryAgent (Port 9999)                       │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  Chat UI (HTML + JS)                                     │   │
│  │  对话界面 / 知识图谱 / 仪表盘 / 三元组管理                │   │
│  └──────────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  LLM Client (Qwen 3.7+ @ DashScope)                      │   │
│  │  对话生成 / 记忆提取 / 矛盾分析                           │   │
│  └──────────────────────────────────────────────────────────┘   │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  CogniMem Client (HTTP 透传)                              │   │
│  │  透明代理到引擎层                                          │   │
│  └──────────────────────────────────────────────────────────┘   │
└──────────────────────────────────┬──────────────────────────────┘
                                   │ HTTP / REST
                                   ▼
┌─────────────────────────────────────────────────────────────────┐
│                    CogniMem Engine (Port 8001)                   │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  提取层: 规则 0 Token → 缓存复用 → LLM 兜底               │   │
│  │  ▸ 30+ 中文句法模式（正则匹配, <1ms, 0 tok）             │   │
│  │  ▸ 推理链缓存（difflib 相似度, 1h TTL, 0 tok）            │   │
│  │  ▸ LLM 提取（仅复杂句, 结构化 JSON 输出）                  │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  事实网络: 核心存储引擎                                    │   │
│  │  ▸ 三元组 (subject-predicate-object) 去重与合并            │   │
│  │  ▸ 置信度贝叶斯更新（来源权重 + 冷启动加速）               │   │
│  │  ▸ L1/L2/L3 三级矛盾检测（否定/冲突/上下文）               │   │
│  │  ▸ 重要性评分 + 自适应 TTL                                │   │
│  │  ▸ 三级缓存（LRU 5min / 查询 60s / 统计 30s）             │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  召回路由: 三级智能路由                                   │   │
│  │  L0: TTL 缓存匹配（<1ms, 0 tok）                         │   │
│  │  L1: 数据库精确匹配（subject/object/tag）                 │   │
│  │  L2: 语义扩展 + 关联事实图遍历                            │   │
│  │  L3: pgvector 向量搜索（仅当以上不足时）                   │   │
│  │  排序: 置信度×50% + 重要性×20% + 新鲜度×20% + 相关度×10% │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  ┌──────────────────────────────────────────────────────────┐   │
│  │  睡眠期整合（5min 空闲自动触发）                          │   │
│  │  ▸ 记忆抽象化: 碎片事实 → 高层归纳（如"冰美式"+"拿铁"    │   │
│  │    → "咖啡饮品"）                                         │   │
│  │  ▸ 重复合并: 相同三元组去重 + 证据聚合                    │   │
│  │  ▸ 模式提升: 高频访问事实 → 核心信念                     │   │
│  │  ▸ 艾宾浩斯遗忘: 自适应半衰期 7~60 天，核心信念不衰减    │   │
│  └──────────────────────────────────────────────────────────┘   │
│                                                                  │
└──────────────────────────────────┬──────────────────────────────┘
                                   │ psycopg2
                                   ▼
┌─────────────────────────────────────────────────────────────────┐
│                     PostgreSQL / CockroachDB                     │
│  ▸ facts 表: 三元组 + 置信度 + 重要性 + 证据                    │
│  ▸ fact_versions 表: 版本链追溯                                 │
│  ▸ contradictions 表: 矛盾关系记录                              │
│  ▸ confidence_log 表: 置信度变更日志                            │
│  ▸ agents 表: Agent 元数据                                      │
│  ▸ pgvector 扩展: 向量相似度搜索                                │
└─────────────────────────────────────────────────────────────────┘
```

## 记忆生命周期

```
用户说"我喜欢喝冰美式"
        │
        ▼
┌─────────────────────┐
│ 规则提取 (0 Token)   │ ← "我" + 喜欢 + "冰美式" → 命中 SIMPLE_PATTERNS
│ → 用户|喜欢|冰美式   │
└─────────┬───────────┘
          ▼
┌─────────────────────┐
│ 矛盾检测             │ ← 扫描已有事实
│ → 无矛盾             │ ← 没有 "不喜欢冰美式"
└─────────┬───────────┘
          ▼
┌─────────────────────┐
│ 存入事实网络          │
│ → 置信度: 0.65       │ ← 规则提取基准置信度
│ → 类型: preference   │
│ → 标签: [咖啡, 饮品]  │
│ → 证据: 原文保留      │
└─────────┬───────────┘
          ▼
          │ 用户问"我想喝什么？"
          ▼
┌─────────────────────┐
│ 三级路由召回          │
│ L0: 缓存命中 → 秒回   │ ← 0 Token
│ → 用户|喜欢|冰美式    │
└─────────┬───────────┘
          ▼
          │ 时间流逝...
          ▼
┌─────────────────────┐
│ 艾宾浩斯衰减          │ ← 7天没访问 → 置信度降 0.65→0.48
│ → 如果核心信念: 不衰减 │ ← 访问≥10次 + 置信度≥0.9
└─────────┬───────────┘
          ▼
          │ 用户又说"我不喜欢冰美式了"
          ▼
┌─────────────────────┐
│ LLM 提取             │ ← 复杂句，规则不够
│ → 用户|不喜欢|冰美式   │
│ → 矛盾检测 → L1 deny  │ ← 喜欢 vs 不喜欢
│ → 双方置信度下降       │ ← 旧 0.48→0.38，新 0.6→0.4
│ → 主动追问: "你之前说  │
│   喜欢，现在不喜欢了？"  │ ← 矛盾驱动学习
└─────────┬───────────┘
          ▼
┌─────────────────────┐
│ 睡眠期整合 (5min后)   │
│ → 标记为已解决        │ ← 用户确认"现在不喜欢了"
│ → 旧事实降级          │
│ → 新事实提升为信念     │
└─────────────────────┘
```

## 为什么 CogniMem 与众不同

### 对比传统方案

| 能力 | 普通 RAG | Mem0 | CogniMem |
|------|---------|------|----------|
| 存储结构 | 文本块 + 向量 | 元数据 + 向量 | **三元组 + 图 + 向量** |
| 提取成本 | 每次调 LLM | 每次调 LLM | **规则 0 tok → 缓存 0 tok → LLM** |
| 矛盾检测 | ❌ | ❌ | **L1/L2/L3 + 主动追问** |
| 遗忘机制 | 固定 TTL | 固定 TTL | **艾宾浩斯自适应** |
| 抽象化 | ❌ | ❌ | **碎片→高层归纳** |
| 置信度 | ❌ | ❌ | **贝叶斯 + 来源权重** |
| 版本历史 | ❌ | ❌ | **完整版本链** |

### Token 效率对比

| 场景 | 传统方案 | CogniMem | 节省 |
|------|---------|----------|------|
| 简单句"我喜欢吃火锅" | 500 tok (LLM 提取) | **0 tok** (规则提取) | 100% |
| 相似句"我爱喝咖啡" | 500 tok | **0 tok** (缓存命中) | 100% |
| 复杂句"虽然今天下雨但我还是想去打篮球" | 500 tok | 500 tok (LLM 提取) | 0% |
| **加权平均** | **~480 tok** | **~120 tok** | **75%** |

## 快速开始

```bash
# 1. 克隆项目
git clone https://github.com/1421906110/qwen-memoryagent
cd qwen-memoryagent

# 2. 配置环境
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. 配置 .env
echo "QWEN_API_KEY=your_key_here" >> .env
echo "QWEN_BASE_URL=https://dashscope-intl.aliyuncs.com/compatible-mode/v1" >> .env

# 4. 启动引擎
uvicorn cognimem.main:app --port 8001 --host 127.0.0.1

# 5. 启动 UI
uvicorn memory_agent.main:app --port 9999 --host 127.0.0.1

# 6. 打开浏览器
open http://localhost:9999
```
