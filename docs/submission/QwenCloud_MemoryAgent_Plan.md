## 🏗️ 技术架构（参考）

```
User → Chat API → Qwen LLM (qwen-max)
                       ↕
            ┌──── MemoryAgent ────┐
            │  Store | Recall      │
            │  Groom | Decay       │
            │  Conflict Resolution │
            └───────┬──────────────┘
                    ↕
            ┌──── Storage ────┐
            │  Vector DB      │
            │  (SQLite/Qdrant)│
            │  + Metadata     │
            └─────────────────┘
```

### 关键差异点（vs 对手）
1. **完整的记忆生命周期管理** — 不是简单的存/查，而是创建 → 验证 → 衰减 → 冲突解决 → 遗忘
2. **Ebbinghaus 遗忘曲线** — 科学地管理记忆权重
3. **1M token 窗口** — 能消化超长上下文，这是 Qwen 的独有优势
4. **跨会话用户画像** — 从多个 session 累积用户偏好
