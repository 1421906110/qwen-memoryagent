## 二、逐项详情

### 2.1 启动优化（P0）

**文件：** `main.py`

**改动：** 首次启动运行完整 LLM 测试后创建 `.cognimem_startup_done` 标记文件。后续启动只检查 DB 连通性，不走 LLM。

```python
# 快速启动模式
startup_done_file = Path(__file__).parent / ".cognimem_startup_done"
if skip_test or startup_done_file.exists():
    # 只检查 DB 连通性，0 API 调用
    logger.info("⚡ 快速启动模式：跳过 LLM 验证测试")
```

**效果：** 启动时间 3-5s → 0.5s，每次重启省 ~200 token。

---

### 2.2 缓存系统优化（P0）

**文件：** `fact_network.py`

**改动：**
- L0 缓存从 100 → 1000 条（OrderedDict LRU）
- 添加 TTL 300s 自动过期
- 添加查询缓存（60s TTL，相同 query 秒回）
- 添加统计缓存（30s TTL，避免每次全库扫描）
- `_get_fact` / `_find_existing` / `_get_agent_facts` 全部 TTL 感知

**效果：** 重复查询 0 DB 开销，Dashboard 刷新不再扫全库。

---

### 2.3 主动学习（P0）

**文件：** `brain.py`

**改动：** `ask()` 方法新增 `active_questions` 字段。检测到矛盾时自动生成引导性问题，检测到不确定项时主动请用户确认。

```python
# L1 deny: 直接否定 → 引导用户澄清
"我注意到关于「用户」，之前记录是「喜欢冰美式」，
 但后来又说「不喜欢冰美式」。哪个是准确的？"

# L2 conflict: 间接冲突 → 提醒注意
"有个小矛盾：你提到过「喜欢吃麻辣烫」，但也说过「喜欢日料寿司」。
 这两者好像不太一致，能帮我澄清一下吗？"

# 不确定项: 低置信度 → 主动确认
"我不太确定「用户 住在 北京」是否准确（可信度 40%），你能确认一下吗？"
```

**效果：** 聊天 UI 中 LLM 回复自动附带主动学习问题。

### 2.4 记忆抽象化 ⭐（P1·最大创新）

**文件：** `fact_network.py`

**算法：**
1. 按 (subject, predicate) 分组
2. 组内通过共享标签做并查集聚类
3. 每组 ≥2 个事实 → 找到共同上层类别（标签优先 → LLM 归纳 → 词重叠）
4. 创建抽象事实（置信度 = avg(子事实) × 1.1）
5. 子事实标记为 "abstracted"，链接到抽象父事实

```
抽象前（碎片）：
  用户 喜欢 冰美式     [咖啡, 冷饮]
  用户 喜欢 热美式     [咖啡, 热饮]
  用户 喜欢 冷萃       [咖啡]
  用户 喜欢 火锅       [美食, 辣]
  用户 喜欢 麻辣烫     [美食, 辣]

抽象后（层次化）：
  🧠 用户 喜欢 咖啡（归纳自3条） conf=0.66
    ↳ 冰美式  ↳ 热美式  ↳ 冷萃
  🧠 用户 喜欢 美食（归纳自2条） conf=0.63
    ↳ 火锅  ↳ 麻辣烫
```

**文件改动：** `consolidate()` 顺序调整（抽象化→合并→提升→遗忘），新增 `_abstract_memories()`、`_find_category()`、`_cluster_by_tags()`、`_llm_categorize()`。

### 2.5 推理链缓存（P1）

**文件：** `llm_extractor.py`

**算法：**
- 缓存 LLM 提取结果（存储三元组元数据，非完整 FactTriple）
- 新文本 → difflib 相似度 vs 缓存文本
- 相似度 > 0.8：直接复用，自动适配 object 差异
- 相似度 0.5-0.8：复用但降置信度（×0.85）
- 相似度 < 0.5：正常 LLM 提取
- 缓存大小 500 条，1 小时过期

```
"我喜欢喝冰美式"  → LLM提取 → 缓存
"我喜欢喝热美式"  → 相似度0.85 → ⚡直接复用 → object自动切换为"热美式"
                                    （0 Token！）
```

**效果：** `get_cache_stats()` 可查看命中率和估算节省 Token 数。

### 2.6 艾宾浩斯遗忘曲线（P1）

**文件：** `fact_network.py`

**改动：** `forget()` 从粗暴的"低置信+30天→删除"改为科学衰减模型。

**衰减公式：** `new_conf = conf × 0.5^(days/halflife)`

| 记忆类型 | 半衰期 | 访问修正 |
|----------|--------|----------|
| 抽象概念 | 60 天 | 访问 >10 次 ×1.5 |
| 高置信(≥0.6) | 30 天 | 访问 >5 次 ×1.2 |
| 普通 | 14 天 | — |
| 低置信(<0.3) | 7 天 | — |
| 核心信念 | 永不衰减 | — |

置信度 < 0.1 → 删除。

**效果：** 记忆像人脑一样自然衰退，而非粗暴删除。每次访问 = 一次"复习"，重置衰减时钟。

---

### 2.7 上下文感知召回（P1）

**文件：** `recall.py`

**改动：** `_rank_and_trim()` 评分从"置信度×0.7+重要性×0.3"升级为：

```
评分 = 置信度(50%) + 重要性(20%) + 新鲜度(20%) + 相关度(10%)
```

- **新鲜度：** `1.0 / (1 + days × 0.5)` — 今天访问过=1.0，7天前=0.22
- **相关度：** query 与事实文本的 difflib 相似度评分

**效果：** 最近访问/最近创建的事实排前面，查询匹配度越高越靠前。

---

### 2.8 空闲自动整合（P1·Sleep-Cycle）

**文件：** `fact_network.py` + `brain.py`

**改动：**
- `_last_consolidation` 记录每个 Agent 上次整合时间
- 间隔 300s（5分钟）空闲 → 自动触发 `consolidate()`
- `remember()` / `recall()` / `ask()` 调用时检查

**效果：** 系统像人脑一样在"空闲时"自动整理记忆，无需手动操作。

---

### 2.9 混合提取模式（P1）

**文件：** `llm_extractor.py`

**改动：** 提取优先级：简单句规则(0 Token) → 推理链缓存(0 Token) → LLM 提取

**12 种简单句模式（正则匹配，<1ms）：**

| 模式 | 示例 | 提取结果 |
|------|------|----------|
| 我叫X | "我叫小明" | (用户, 名字, 小明) |
| 我是X | "我是程序员" | (用户, 是, 程序员) |
| 我喜欢X | "我喜欢喝冰美式" | (用户, 喜欢, 喝冰美式) |
| 我讨厌X | "我讨厌吃香菜" | (用户, 讨厌, 吃香菜) |
| 我想/要X | "我想去北京" | (用户, 想要, 去北京) |
| 我去过X | "我去过深圳" | (用户, 去过, 深圳) |
| 我在X | "我在北京工作" | (用户, 在, 北京) |
| 我会X | "我会写Python" | (用户, 会, 写Python) |
| ... | ... | ... |

**限制：** 句子 ≤ 40 字符 + 不含复杂连接词（但是、因为、所以…）。

**效果：** 约 20-30% 的用户输入可被规则覆盖，每次省 50-150 token。
