## 一、系统架构

```
┌─ Web UI (9999) ─────────────────────────┐
│  聊天界面  │  知识图谱  │  仪表盘        │
└──────────────────┬──────────────────────┘
                   │ HTTP
┌─ MemoryAgent ────▼──────────────────────┐
│  转发层（FastAPI）                       │
│  原有 UI/API 接口保持不变               │
└──────────────────┬──────────────────────┘
                   │ HTTP
┌─ CogniMem 引擎 (8001) ─────────────────┐
│  FastAPI · 12 端点                      │

                   │
┌─ PostgreSQL ─────▼──────────────────────┐

│  facts · contradictions · episodes     │
│  confidence_log · agents · fact_versions│
```

## 二、已完成功能清单

### 🔧 核心引擎
| 功能 | 说明 | 状态 |
|------|------|------|
| 三元组事实网络 | subject→predicate→object 结构化存储 | ✅ |
| LLM 三元组提取 | DeepSeek，准确率 83%（vs 规则 33%） | ✅ |
| 三级召回 | L0 Cache → L1 ILIKE → L2 difflib → L3 pgvector | ✅ |
| 置信度细化 | 来源权重（用户/Agent/工具）+ 冷启动×2 | ✅ |
| 矛盾等级 L1/L2/L3 | deny(降双方) / conflict(仅降新) / context(不降) | ✅ |
| 记忆版本链 | 每次变更记录原因 + 新旧置信度 | ✅ |
| LLM 矛盾分析 | 自动判断 contradiction/context/misunderstanding | ✅ |
| 主动遗忘 | 低置信 + 长期未访问 → 自动删除 | ✅ |
| 睡眠整合 | 重复合并 + 模式提升 + 遗忘 | ✅ |

| pgvector 向量搜索 | n-gram 哈希嵌入，384 维 | ✅ |
| 置信度日志 | confidence_log 表记录每次变化 | ✅ |
| 矛盾持久化 | contradictions 表 + 类型标记 | ✅ |

## 三、废弃组件

| 组件 | 原因 | 替代方案 |
|------|------|---------|
| HMS 记忆系统设计报告 | 初稿 | CogniMem 认知记忆系统设计报告 |
| MemoryAgent SQLite 存储 | 迁移到 PG | PostgreSQL + pgvector |
| 规则提取器（extractor.py） | 准确率低（33%） | LLM 提取器（llm_extractor.py） |
| 旧版置信度（±0.1线性） | 太粗糙 | 来源权重 + 冷启动 + 三级惩罚 |
| 旧版矛盾（只有一种） | 不分等级 | L1 deny / L2 conflict / L3 context |
| 旧图谱（相似度连线） | 无意义 | 三元组知识图谱 |

## 五、启动方式

```bash
# 1. 启动 CogniMem 引擎（8001）
cd ~/Desktop/cognimem
source venv/bin/activate
uvicorn main:app --port 8001

# 2. 启动 Web UI 仪表盘（9999）
cd ~/projects/qwen-memoryagent
source .venv/bin/activate
QWEN_API_KEY=sk-xxx \
QWEN_BASE_URL=https://api.deepseek.com/v1 \
QWEN_MODEL=deepseek-chat \
uvicorn memory_agent.main:app --port 9999

# 3. 浏览器访问
# http://localhost:9999/    ← Web UI
# http://localhost:8001/docs  ← API 文档
```
