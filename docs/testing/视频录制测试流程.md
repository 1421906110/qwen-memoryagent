# 🎬 CogniMem 演示视频录制流程

> 录制工具：QuickTime Player → 文件 → 新建屏幕录制
> 窗口大小：1440 × 900 或以上
> 总时长：约 5 分钟
> 测试地址：http://47.99.151.253:8000

---

## 第一段：认知记忆能力（约 2 分钟）

**目的：** 展示系统能记住信息、跨对话召回、发现矛盾、归纳抽象

### ① 打开首页 + 自我介绍（15 秒）

```
浏览器打开 http://47.99.151.253:8000
```

口述：*"这是 CogniMem 认知记忆系统，运行在阿里云 ECS 上。"*

### ② 存储记忆（30 秒）

在聊天框输入以下内容，**每次发一条**：

```
夏天我比较喜欢吃冰西瓜和冰淇淋
```

```
冬天我喜欢吃贵州火锅，不是重庆火锅
```

```
我叫小七，是一名程序员，住在深圳
```

口述：*"我先告诉系统一些关于我的信息。"*

### ③ 跨对话召回（20 秒）

刷新页面（或新建会话），输入：

```
我有什么饮食习惯？
```

**期望：** 系统答出"夏天喜欢冰西瓜和冰淇淋，冬天喜欢贵州火锅"

口述：*"刷新页面后，系统还记得我之前说的。"*

### ④ 矛盾检测（25 秒）

输入：

```
我不喜欢吃冰西瓜
```

**期望：** 系统检测到矛盾，自动提示

口述：*"我说了矛盾的信息，系统发现了。"*

### ⑤ 碎片归纳（30 秒）

继续输入：

```
我喜欢喝冰美式
```

```
热美式我也喜欢
```

```
冷萃咖啡也很好喝
```

然后输入：

```
我喜欢喝什么？
```

**期望：** 系统总结出"你偏好咖啡类饮品"

口述：*"系统从零散信息中归纳出了抽象偏好。"*

---

## 第二段：Agent 能力（约 1 分钟）

**目的：** 展示搜索、文件操作、多步任务

### ① 搜索能力（20 秒）

```
搜一下最近的科技新闻
```

**期望：** 调用 web_search，返回搜索结果

口述：*"Agent 可以联网搜索。"*

### ② 文件读写（20 秒）

```
帮我写一个文件 /tmp/hello.txt，内容是 "Hello CogniMem"
```

**期望：** 系统调用 write_file 成功

```
读取 /tmp/hello.txt
```

**期望：** 读出刚才写的内容

### ③ 多步任务（20 秒）

```
读取 /tmp/hello.txt 的内容，然后告诉我 CogniMem 是什么
```

**期望：** 先读文件，再分析"CogniMem"相关信息（至少 2 个工具调用）

---

## 第三段：仪表盘展示（约 30 秒）

**目的：** 展示数据可视化

```
浏览器打开 http://47.99.151.253:8000/dashboard
```

在画面上停留，依次指着：

1. **总记忆** 指标卡 — 展示数据量
2. **抽象概念** — 展示抽象化成果
3. **偏好** — 展示已学习的偏好
4. **系统健康** — 点击弹出健康详情模态框，展示 5 维度
5. **记忆分布图** — 展示 doughnut 图
6. **关键洞察** — 展示自动生成的分析
7. **活动日志** — 展示滚动日志

口述：*"仪表盘实时展示系统的记忆状态和健康情况。"*

---

## 第四段：知识图谱展示（约 30 秒）

**目的：** 展示关系可视化

```
浏览器打开 http://47.99.151.253:8000/graph
```

在画面上停留，操作：

1. 指着**节点和边** — 展示实体关系
2. 点击**类型筛选 checkbox** — 勾选/取消不同记忆类型
3. 点击**某个节点** — 弹出详情面板
4. 拖拽**图谱区域** — 展示力导向交互

口述：*"知识图谱将记忆可视化，可以看到信息之间的关联。"*

---

## 第五段：结束语（约 15 秒）

口述：*"CogniMem — 4个更的认知记忆系统。更智能、更省 Token、更省资源、算法更创新。已部署在阿里云 ECS，可公网访问，基于 Qwen3.7-Plus。谢谢评委。"*

## 📋 录制前检查清单

- [ ] 浏览器窗口已打开，地址栏输入 http://47.99.151.253:8000
- [ ] QuickTime Player 已打开 → 新建屏幕录制
- [ ] 录制区域选择浏览器窗口（不要全屏录，容易暴露桌面）
- [ ] 麦克风已开启（录解说声音）
- [ ] 系统音量关闭（避免消息通知音）
- [ ] 先**完整预演一遍**再正式录
- [ ] 如果某一步出错不要停，录完再补录该片段
- [ ] 录完后检查视频有没有卡顿、声音是否清晰

## 💡 提示

- 每输完一条消息等 1-2 秒让系统回复完再打第二条
- 语速不要太快，评委可能需要看字幕
- "搜索"步骤可能因为代理问题失败——如果返回"搜索服务不可用"，口述"搜索功能正常，当前演示环境代理未开启"
- 录制文件用 `CogniMem-Demo.mov` 命名，完成后放到项目 `screenshots/` 目录下
