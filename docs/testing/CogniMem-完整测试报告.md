| "用户住在深圳南山" | `(用户, 住在, 深圳南山)` | ✅ |
| "用户目标是学会Python" | `(用户, 目标, 学会Python)` | ✅ |
| "用户喜欢蓝色" | `(用户, 喜欢, 蓝色)` | ✅ |
