# 🎬 CogniMem 演示视频 — 快速版（约 2 分钟）

> 录制工具：QuickTime Player → 文件 → 新建屏幕录制
> 窗口大小：1440 × 900
> 总时长：约 2 分钟
> 测试地址：http://47.99.151.253:8000
> **节奏提示：** 每步停顿不超过 2 秒，语速适中，直奔主题

---

## 开场（15 秒）

```
浏览器打开 http://47.99.151.253:8000
画面停在聊天界面
```

**口述：**
*"大多数 AI 记忆系统直接把对话原文塞进上下文——费 token、召回差。CogniMem 不一样。四个字：更智能、更省 Token、更省资源、算法更创新。"*

---

## 第一段：🧠 更智能 — 跨对话记忆（40 秒）

**口述：** *"我先告诉系统一些信息，然后刷新页面——看它还记得吗。"*

依次输入（每次一条，不等回复打完就输下一条）：

```
夏天我喜欢吃冰西瓜和冰淇淋
```

```
冬天我喜欢吃贵州火锅，不是重庆火锅
```

```
我叫小七，是一名程序员，住在深圳
```

👉 立即**刷新页面**（F5 / Cmd+R），输入：

```
我有什么饮食习惯？
```

**期望：** 秒回"夏天喜欢冰西瓜和冰淇淋，冬天喜欢贵州火锅"

**口述：** *"刷新页面、新建会话，记忆还在。这不是硬匹配关键词，是结构化理解。"*

👉 接着输入矛盾信息：

```
我不喜欢吃冰西瓜
```

**期望：** 系统检测矛盾

**口述：** *"发现矛盾了——它不只是存，还会思考。"*

---

## 第二段：💰 更省 Token — 零成本提取（15 秒）

**口述（画面停在对话界面）：**
*"'我喜欢冰西瓜'这种句式，规则直接解析，0 Token 消耗。'你叫什么名字'缓存命中，0 Token。只有复杂句子才调大模型——实际调用不到 10%。"*

**不需要额外操作，边指屏幕边说。**

---
